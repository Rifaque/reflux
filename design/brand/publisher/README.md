# RSX Develops Brand Assets

This folder contains the RSX Develops wordmarks and usage guidelines, alongside information about the separate favicon assets.

## Wordmarks

- `rsx-develops-wordmark-dark.png` — white lettering with a transparent background. Use on dark backgrounds.
- `rsx-develops-wordmark-light.png` — near-black lettering with a transparent background. Use on light or white backgrounds.
- `rsx-develops-wordmark-dark-2x.png` / `rsx-develops-wordmark-dark-4x.png` — high-resolution exports for dark-theme use.
- `rsx-develops-wordmark-light-2x.png` / `rsx-develops-wordmark-light-4x.png` — high-resolution exports for light-theme use.

The wordmarks contain only **RSX Develops**. The `SOFTWARE · SYSTEMS · PROJECTS` tagline is intentionally excluded. The transparent exports include extra bottom padding to preserve the `p` descender in `Develops` without clipping or overprinting.

## Favicon Assets

The favicon files are maintained separately and are not included in the wordmark-focused archive.

Existing favicon assets include:

- `favicon.ico`
- PNGs at 16, 32, 48, 180, 192, and 512 px, in dark and light variants.

Use the existing favicon and app-icon files in the portfolio's `public` assets. Do not derive favicons from the wide wordmarks; use the approved favicon artwork for browser tabs and app icons.

## Usage Guidelines

- Use the **light wordmark** on light backgrounds.
- Use the **dark wordmark** on dark backgrounds.
- Preserve the original aspect ratio; never stretch the images.
- Use `object-fit: contain` or an equivalent approach.
- Set the image width explicitly while allowing the height to remain automatic.
- Avoid CSS filters that alter the custom lettering.
- Place the transparent PNGs directly over the corresponding theme background.

## Source and Limitations

The lettering is based on the supplied RSX Develops concept-board reference. The assets are raster PNGs, not editable SVG masters.

Some earlier concept-board crops may retain panel backgrounds and should be treated as reference assets rather than final transparent artwork. The polished wordmark exports are intended for direct website use.

For future refinement, recreate the lettering as clean vector paths with appropriate clear space, then export transparent PNG and SVG versions.
