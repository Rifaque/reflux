# Third-party software in Reflux's builds, as the About page lists it (docs/RELEASE.md, "Third-party notices").
#
# One component per line, six fields separated by "|":
#   name | license | texts | targets | modules | note
#
#   texts    the files in legal/licenses shown for it, in order, separated by spaces
#   targets  where it is part of the build: android, desktop, or both
#   modules  Maven modules it covers, as group:name patterns where * matches anything; empty for software
#            that is not a Maven module (native code)
#   note     one sentence shown with it, or empty
#
# `./gradlew check` fails when a module on a shell's runtime classpath is covered by no line for that target,
# or when a line names modules none of which that target has. Licenses here were read from each module's POM
# and from the license files inside its artifacts (2026-10-19); keep that evidence when adding a line.
