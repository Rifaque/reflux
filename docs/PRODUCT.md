# Reflux Product

## Positioning

**Reflux is a media player on steroids.**

It is not primarily a Jellyfin client, server dashboard, or file browser. The core product is an exceptional media playback experience surrounded by intelligence that makes playback effortless.

## Product promise

> Your media, wherever it lives. Automatically understood, beautifully organized, intelligently played.

## The magic moment

The defining experience is:

> **"Holy shit, it found and organized everything automatically."**

A user should be able to provide an ordinary folder of media and quickly receive a coherent, richly identified virtual library without first preparing the files for Reflux.

## Pillars

### 1. Play

A serious playback experience with hardware acceleration, practical modern codec support, HDR where supported, multiple audio tracks, subtitles, chapters, resume, playback speed, picture controls, and platform-appropriate advanced playback features.

### 2. Understand

Parse filenames and folder structure, identify titles and episodes, fetch metadata and artwork, calculate confidence, and provide a fast manual correction flow.

### 3. Organize

Create a virtual media library without changing the user's files. Support movies, shows, seasons, episodes, collections, favorites, continue watching, smart collections, and version awareness.

### 4. Adapt

Adapt the experience to touch, pointer, keyboard, controller, and TV remote input. The interface should morph smoothly when the active input method changes.

### 5. Stay useful

Cache the library, metadata, artwork, and state locally so the user can still browse and search even when a source is disconnected.

## Default experience requirement

This is a hard requirement, not a later polish item.

The first-run product must already be:

- visually coherent,
- sensibly organized,
- appropriately animated,
- easy to navigate,
- correctly configured for normal playback,
- conservative about advanced settings,
- useful without account creation,
- useful without manual metadata setup.

Customization is additive. It must never be a prerequisite for a good first experience.

## Non-goals for the core

Reflux should not become:

- a media-server administration console,
- a mandatory cloud service,
- a social network,
- a file-management tool that rearranges a user's library,
- an AI demo that requires an LLM for basic search or playback.
