libmpv in this Reflux package
=============================

Reflux for Windows includes libmpv-2.dll: libmpv (mpv's client library) version 0.42.0, with FFmpeg 9.0.2 and the
other libraries listed in third-party/components.txt under "Inside libmpv-2.dll" linked into it. RSX Develops built
it from the unmodified source releases of each of them; no source was patched. It is licensed under the GNU Lesser
General Public License, version 2.1 or later, as built: mpv was configured with -Dgpl=false, and FFmpeg without
--enable-gpl, --enable-version3, or --enable-nonfree. The LGPL text is third-party/licenses/lgpl-2.1.txt; the
licenses of the libraries inside it are in third-party/licenses.

Reflux is a separate program. It loads libmpv-2.dll at run time by name from this folder and is not linked against
it: you may replace libmpv-2.dll with another build of libmpv 2.x (one you built or modified yourself), and Reflux
will use it.

Source code
-----------

The complete corresponding source code of this libmpv-2.dll is published beside every GitHub release of Reflux for
Windows, as the asset named reflux-<version>-libmpv-source.tar.xz at https://github.com/Rifaque/reflux/releases.
It holds the exact source archive of mpv, FFmpeg, and every library linked into the DLL, each with its SHA-256, and
the scripts and build environment that built it (tools/libmpv: a Dockerfile, build.sh, and sources.txt). Following
tools/libmpv/README.md rebuilds a DLL identical byte for byte (SHA-256
e52f3f45e6a924843114eb696208fb764f7337226b0b0f03a39df8bd399090a4).

The same source is also available from RSX Develops on request, at no charge beyond the cost of providing it, for
at least three years from the date this package was distributed, at the address on the Reflux website's support
page (https://reflux.rsxdevelops.dev/support).
